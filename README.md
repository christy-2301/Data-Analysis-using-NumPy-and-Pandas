# Python DA Assignment 1: Data Analysis Using NumPy and Pandas

## 📌 Project Overview
This assignment focuses on practicing basic data analysis operations using Python libraries such as NumPy and Pandas.

## 🎯 Objectives
- Create and manipulate NumPy arrays.
- Perform numerical calculations on temperature data.
- Practice indexing, slicing, and Boolean filtering.
- Create and manipulate Pandas Series.
- Explore and analyze transaction data using Pandas DataFrames.
- Perform data filtering, grouping, and aggregation.

## 🛠️ Tools and Technologies
- Python
- NumPy
- Pandas
- Google Colab / Jupyter Notebook

## 📊 Tasks Performed

### 1. NumPy Array Operations
- Created 1D and 2D arrays containing temperature data for two weeks.
- Checked array shape, data type, and number of elements.
- Converted Celsius temperatures to Fahrenheit.
- Calculated maximum, minimum, and mean temperatures.
- Practiced array indexing and slicing.

### 2. Pandas Series
- Created a Series containing student marks with custom index labels.
- Practiced indexing using `loc` and `iloc`.
- Applied Boolean masking to filter marks.
- Updated and removed Series entries.
- Calculated CGPA by dividing marks by 10.

### 3. Pandas DataFrame
- Created a transaction dataset with transaction IDs, product categories, regions, and amounts.
- Explored the dataset using `head()`, `tail()`, `shape`, `columns`, and `dtypes`.
- Selected columns and filtered rows based on conditions.
- Used `value_counts()` and `unique()` to explore categorical data.
- Grouped transactions by region and calculated average amounts.
- Updated transaction values, created a 10% discount column, and removed specified rows and columns.

## 📚 Key Learnings
- Understanding NumPy arrays and their properties.
- Using Pandas Series and DataFrames for data manipulation.
- Applying filtering, indexing, and slicing techniques.
- Performing basic data exploration and aggregation.
- Improving Python programming and data analysis skills.
